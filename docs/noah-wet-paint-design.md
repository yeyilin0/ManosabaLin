# 诺亚 · 机制三设计

> **当前状态**：只有「**机制三会糊住卡牌**」是确定的，其余全部未定。
> 本文档只谈**设计**；技术实现（附魔 / 牌堆 / 联机）在机制定稿之前一律不写。

---

## 一、已确定的两条机制

| | 机制 |
|---|---|
| **一** | 移除卡的效果 → 得**颜料**（三原色 + 修饰色）；效果全移除 → **白纸**；耗颜料 → 白纸得**随机效果** |
| **二** | 打出带**指令**关键词的卡 → 随机触发**七种武器攻击**；七种集齐一轮 → 得**奖励卡牌** |

## 二、约束

**单体系独立玩 + 混合玩都可以** ⇒ 每条机制必须自闭环；跨机制接口只能是加成，不能是解锁。

---

## 三、先回答「玩家为什么要让自己的卡被糊住」

这是机制三的**唯一入口问题**。答案只有三类：

| | 含义 | 收益来源 |
|---|---|---|
| A | 糊住是**代价** | 收益在别处（打出强力卡才接受） |
| B | 糊住是**保护** | 敌人够不着 |
| C | 糊住是**过程** | 之后会变成别的 |

⇒ 三条机制的收益必须**互不重复**，否则就不是三条：

| 机制 | 产出什么 |
|---|---|
| 一 | **内容**（卡上有什么效果） |
| 二 | **输出**（打出什么攻击） |
| 三 | **？** |

⇒ 机制三**绝不能产出「内容」**（那是机制一）、**绝不能产出「攻击」**（那是机制二）。

---

## 四、提案：机制三 = 「晾干」，产出「次数」

### 规则

1. 诺亚的一部分卡**打出后不进弃牌堆**，而是盖着颜料、以「**未干**」状态回到牌堆
2. **未干的卡看不见内容、打不出**（卡面被糊住）
3. 每回合自动干 1 层；**层数 = 卡自己的属性**（薄画 1 层、厚画 3 层）
4. 干透 → 颜料洗净 → **可以再打**

### 收益是「次数」，不是强度

⇒ **一张强力卡在一场战斗里能用好几次。**

这是机制一和机制二都产不出的第三种收益，所以不在它们地盘上：

| 机制 | 产出 | 维度 |
|---|---|---|
| 一 | 改**内容** | 卡上有什么 |
| 二 | 给**输出** | 打出什么 |
| 三 | 给**次数** | 能打几次 |

### 为什么「糊住」必须是这个理由

卡为什么被糊住？因为**刚画完，颜料还没干**。

不是敌人干的、不是诅咒——是**诺亚自己的画还没干**。这是「糊住」最自洽的物理来源，
也是唯一不需要额外解释的那个。

而且"水加多加少决定干得快慢" ⇒ **水多（厚画）干得慢、水少（薄画）干得快**，
正好让介质管住「时间」，与颜色无关。

## 五、独立玩 / 混合玩

### 独立（纯机制三 = 循环流）

- 只带少数强力卡，靠**循环**取胜
- 加速晾干的卡 / 遗物属于机制三自己 ⇒ **不需要颜料，零外部依赖**
- 玩法：**少数精锐反复上场**

### 混合（三条的咬合）

| 接口 | 方向 | 效果 |
|---|---|---|
| **洗色** | 颜料 → 晾干 | 花颜料洗掉未干的颜料 ⇒ 立即取回。**给机制一的颜料一个去处** |
| **一次晾干** | 七武器集齐 → 晾干 | 集齐一轮时所有未干的卡立即干透 ⇒ 爆发窗口 |
| **未定型** | 白纸 → 晾干 | 机制一画出的随机效果，若卡还没干，则**效果还没定型** |

⇒ 全是加速 / 变数，**没有一条是解锁**。

---

## 六、为什么这样三条才不撞车

| 想干什么 | 玩哪条 |
|---|---|
| 改卡的效果 | 机制一（颜料 / 白纸） |
| 打出什么攻击 | 机制二（指令 / 七武器） |
| **一张卡能打几次** | 机制三（晾干） |

⇒ 三条各管一个维度，**任意一条单拿出来都能撑一套打法，合起来互不干扰**。

## 八、机制二细化（参照里恩的「索引家族」）

> 里恩（边狱巴士 HoS 模组的 boss）用一套 **武器集 + 指令书(Prescript) + 洗牌袋循环** 来组织「多武器多指令」。
> 诺亚是**玩家角色**（里恩是 boss），所以里恩的「条件/进度/结算」三段式要转译成玩家侧的「指令名 + 攻击形状 + 触发/结算」。
> 以下借用里恩的结构，但不照搬 boss AI。

### 8.1 里恩体系的三条可借鉴点

| 里恩的做法 | 诺亚怎么用 |
|---|---|
| 固定武器集，每把一个具名 + 一个美术路径 | 七色 = 七把武器，每把一个名 + 一张武器图（`weapon_{色}.png`） |
| 指令书是**具名种类**（27 种），每种带【标签】+ 三段文字 | 七色 = 七种具名指令，每种一句【形状】描述 |
| 从**洗牌袋**抽指令，`RefillBag`+`Shuffle` 保证不连抽重复 | 七色用**一个洗牌袋**循环：集齐一轮前不重复出现（替代原设计的纯随机） |
| 阈值随人数/阶段缩放（`ThresholdFor`） | 若指令带数值（如连击次数、削弱层数），按当前玩家数缩放 |

### 8.2 七色 ↔ 武器 ↔ 指令（最终表）

| 色 | 衣服 | 武器 | 指令 | 攻击形状（参照里恩的指令类型） |
|---|---|---|---|---|
| 红 | 红·军装披风 | **大剑** | **斩** | 单体重击（单发最高伤）— 贴近里恩 `DecisiveBlow/重断` |
| 橙 | 橙·猫耳虎纹 | **指虎** | **连** | 单体多段连击（次数最多）— 贴近里恩 `Relentless/连击` |
| 黄 | 黄·运动休闲 | **大锤** | **击** | 单体重钝 + 眩晕/击退 — 重钝控制位 |
| 绿 | 绿·新中式（立领＋超大喇叭袖） | **长枪**（里恩 spear） | **架** | 防御反击型：举枪格挡、随即刺击回敬 — 七把唯一防御位（贴近里恩 `Unshaken/不可撼动` 的「保有格挡」概念） |
| 蓝 | 蓝·战术装 | **镰刀**（里恩 scythe） | **刈** | 全体横扫 + 吸血 — AoE 位（里恩武器集里的镰刀） |
| 靛 | 靛·忍装 | **刺剑**（里恩武器，rapier） | **贯** | 精准多段穿刺、贯穿多目标 — 散射/多目标位（里恩武器集里的刺剑，细长穿刺，贴合忍装气质） |
| 紫 | 紫·礼裙 | **锁链**（里恩武器，chain） | **缚** | 全体链击 + 削弱（虚弱/易伤）— 全体 debuff 位（里恩武器集里的锁链，横扫束缚，贴近 `Brand/烙印` 的施加负面，但做成 AoE） |

> 七把武器的**攻击形状互不重样**，覆盖：单发重击 / 多段连击 / 重钝控制 / 全体横扫 / 防御反击 / 散射 / 全体削弱 —— 正好七种。

### 8.3 借用里恩的「洗牌袋循环」

- 原设计写的是「随机触发七种武器」——改为**洗牌袋**：把七色放一袋、洗牌，抽空才重洗。
- 效果：同一场战斗里七色**均匀轮换、不连抽同一色**，集齐一轮时触发原设计的「奖励卡牌」（与机制三的「一次晾干」接口同源，都是「集齐七色」）。
- 实现提示（仅设计层）：七色对应七张「指令卡」或七个指令标记，抽牌/触发走 bag 而非纯 `Rng.NextInt`。

### 8.4 两条硬约束（沿用之前结论）

1. **武器只产出「攻击」，不碰颜料/水**：七把全部取自里恩武器集（大剑/大锤/指虎/长枪/镰刀/刺剑/锁链），纯粹表现「打出去什么形状的伤害」——别写成「泼漆上色」（机制一的地盘），也别做水属性（机制三晾干的地盘）。
2. **颜色 = 指令 = 武器 = 衣服 四者同绑**：打红指令 → 换红衣 → 用剑。玩家能主动组「想要哪种攻击形状」，随机性只留给「集齐一轮→奖励」与 bag 循环。
- 未干的卡去**手上**还是**牌堆**（决定占不占手牌位）
- 加速晾干的具体成本
- 干透时卡的强度**完全不变**还是另有变化（若另加，必须先确认不与机制一撞车）

### 8.5 七套衣服统一配色规范（视觉定稿）

**唯一规则：一套衣服 = 黑衣料（主） + 一个色相（深/主/浅三级，作湿漆） + 白（≤10% 点睛）**。禁止第二色相、荧光色、彩虹、彩色印花。所有花纹（条纹/蕾丝/刺绣/虎纹/格纹）**只用同一个色相的明度差**画，不得用另一种颜色画图案。

统一手法（绑定七套的是「画风」不是「头发/白」；**武器不进服装改色提示词，单独处理**）：

1. **每套以黑衣料为基色，本色占相当面积，二者靠「渐变 + 厚涂」咬合，不引入第二个色相。** 七套共用同一套「黑底 + 本色湿漆」语法：黑色衣料为骨，本色以渐变铺到受光面 / 肩胸 / 大色块，并以厚涂堆出肌理。色相不同 → 远看七色、近看同画风，这才是统一的根源。
   - **渐变衔接**：受光面 / 大色块 = 饱和本色，向下 / 阴影面 / 下摆 = 沉入黑；本色与黑用平滑渐变晕开，不做硬边。
   - **厚涂肌理**：大色块保留可见笔刷方向与颜料堆积感，重点图案（虎纹 / 条纹 / 徽记）用厚涂堆出立体脊线，像未干厚颜料。渐变软化边界、厚涂给出体积，二者结合。
   - ⚠️ **比例要平衡**：黑与本色都要有存在感（黑约 40~55%、本色约 45~60%，随光照浮动）。既不满身本色，也不黑衣点漆。
2. **头发不改。** 七套各自保留图里的发色（蓝发 / 彩虹 / 绿发 / 白毛 / 黑发……），不强行统一成银白。区分度交给发型+发色，统一性交给上面的渐变涂装。
3. **白只占极小面积（5%~10%）只点睛**，已写入共用端点表，删掉「内衬/蕾丝/袜/高光全用白」的旧规则。
4. **武器不进服装改色提示词（单独出图 / 另处理）**：若需统一配色，黑金属为主 + 本色浅阶刃口 / 纹路光，不另设第二色相。
5. **配件（靴 / 手套 / 腿环 / 披风）同规则**：按「黑基 + 本色渐变厚涂」处理，与衣身同画风，不可漏改。例如靴口 / 靴筒橙漆渐变沉黑，呼应裙摆下缘。
6. **层次感 / 结构是硬要求（2026-10-21 用户纠正）**：每套必须读出「多件叠穿」（内搭 / 外衣 / 下装 / 配件），各件边缘清晰、材质有别（贴身哑光布 vs 外层厚呢 / 皮革）、有前后投影与布褶；**虎纹 / 条纹等图案只用在 1~2 件上作点睛，绝不铺满全身把衣服糊成一片**。手套必须分指（露指手套 / 臂套），大衣必须有版型（领 / 肩 / 袖筒 / 布褶），禁止融合成团。**层次感同时由「本色→黑渐变」承担**：受光 / 凸起面偏饱和本色、褶皱凹陷 / 层叠内侧沉黑，让颜色本身交代前后上下；修好结构不能把颜色弄没——本色要贯穿各层（黑约 40~55% / 本色约 45~60%），不缩成一点。
7. **大体积外套只做干净的形，禁止铺虎纹 / 高饱和满印（2026-10-21 用户对照 image#2 指出）**：蓬松大衣 / 斗篷的廓形与垂坠本身就是好搭配，一旦在高饱和大体积上铺有机纹理（虎纹等），会糊成「脏 / 焦 / 霉」的恶心感。⇒ 大衣做**纯黑干净哑光 + 克制的彩色内衬 / 边缘**；**高辨识图案（虎纹等）只给贴身小件（上衣 / 袖口）**。彩色内里由裙 / 上衣 / 靴撑起，大衣当「黑框」把颜色框住——这才是搭配感。
8. **白≤10% 的例外：靛套白丝袜保留白色（2026-10-21 用户指定）**。靛·刺剑原图的白长袜**保持白色**，不收进靛/黑——它是这套的辨识点与「留白」呼吸位；可带极浅靛灰阴影与膝上靛色收边，但袜身必须是白。其余「白裙 / 白上衣 / 白内衬」仍按原规则收进本色阶。
9. **裙 / 靴筒必须做渐变，不许平涂（2026-10-21 用户对照橙·指虎基准图指出）**：橙套里裙、大衣、靴筒是同一套「本色从亮沉进黑」的晕染语言 —— 受光 / 上缘饱和本色，向下 / 下摆沉黑，中段平滑过渡。任何一套的**裙摆都不允许处理成一块死黑或一块死本色**，必须带本色↔黑的渐变；靛套的裙（白裙摆 / 靛内裙）同理。
10. ⚠️⚠️ **改色必须照搬原图的「明暗骨架」，不许把亮部翻成暗部（2026-10-22 用户对照紫套原图指出）**：动手前先测绘原图 —— 哪些区域是白/亮、哪些是黑、面积各占多少；改色时**亮区换本色的浅/中阶（明度基本不变）、暗区保持黑、面积比照抄**。把大面积白翻成黑 = 整张画的气质反转：紫套首版就把「白为主 + 黑蕾丝点缀」翻成「黑为主 + 紫点缀」，结果衣服糊成一团黑块、与银白长发和浅色披纱打架，用户判为「配色怪怪的」。反过来说，原图本来暗部多（如橙·指虎的大衣），就别硬塞大面积本色。**「黑底 + 本色」不是无条件公式，而是原图本来偏暗时的表达；原图偏亮时，本色就该占据原来的亮部面积。**
11. ⚠️⚠️ **图生图改色必须「款式/剪裁一并照搬」，且必须先把款式「读对」（2026-10-22 紫套两次教训）**：原图每件衣物的**类别**、剪裁、长短、叠加次序、体积都要保真。
    - **先读对类别**：紫套原图是「**兔女郎连体衣（高叉露腿）+ 侧腰荷叶 + 一条侧垂长裙摆**」，我先后误读成「超短裤」（漏掉连体衣的高叉剪裁）和「缎带/披纱」（把裙摆判成缎带并禁止）——**读错类别，后面所有提示词全错**。
    - **再锁死廓形**：紫套首版出图把连体衣换成了「包裹全身的紫缎面晚礼服长裙」，露腿剪裁与吊袜带全丢——这是款式漂移，比配色错更糟。
    - ⇒ 提示词里逐件列清并标注「剪裁/长度/位置不变」；负面词要双向堵：既堵「把连体衣变成长裙」，也堵「删掉侧垂裙摆 / 去掉高叉露腿」。

艺术化要点（把「换色」变成「画」）：

- **裙/袍做 ombré**：胸口本色 → 中段本色深阶 → 下摆黑，一气呵成，像被颜料浸染下沉。
- **边缘滴漆**：裙摆、披风角加 1~2 滴同色漆点 / 拖痕，直接点题「湿画」机制。
- **笔触留痕**：大色块保留可见笔刷方向，不要 CG 平涂的塑料感。
- **图案同色明暗**：条纹 / 蕾丝 / 虎纹 / 刺绣全部用「同色深↔浅」画，绝不用第二种颜色。

> 蓝/靛/绿三套必须依次拉开为 **浅蓝 → 深靛偏紫 → 黄绿**，否则玩家在局内分不清当前拿的是哪把武器。
