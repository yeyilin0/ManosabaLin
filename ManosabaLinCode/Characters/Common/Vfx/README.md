# 保留场地特效

`CombatFieldVfxSlot` 管理同一战斗房间中的一个保留场地显示权，跨玩家、跨特效类型。当前接入「真结局」「好结局」的外围光圈，以及「我来亲手，把这一切终结」满足条件时保留的全屏裂纹。

新场地出现后，旧场地退出；旧能力仍然存在，伤害、奖励、卡牌状态和短暂能力反馈继续按原机制执行。角色翅膀、单次攻击、蝴蝶反馈等不占用这个槽位。

## 新场地接入

1. 场景的保留层先保持关闭，将演出控制节点挂到当前 `NCombatRoom` 下。
2. 实际打出新场地时调用 `CombatFieldVfxSlot.Claim(presenter, onReplaced)`。返回 `true` 才开启保留层。
3. 从已有能力恢复显示时使用 `restoreOnly: true`；加载预热和短暂能力通知不能重新抢占场地。被拒绝的恢复必须保持零亮度，不能先显示再淡出。
4. `onReplaced` 只关闭或淡出场地视觉，不移除能力，不提前取消卡牌等待。仍有演出信号需要结算时，保留信号时钟至正常完成。
5. 退场或销毁时调用 `Release(presenter)`。槽位也监听 `TreeExiting` 清理；旧节点退出不会清掉新节点的显示权。

同一个节点重复取得显示权不会替换自身。新显示权先登记，再回调旧场地，因此旧场地释放自己时不会误清新场地。旧场地被替换后，不会因新场地结束而自动恢复。

当前槽位只属于房间，不序列化到存档。新建房间恢复时，第一个有效的 `restoreOnly` 请求可取得显示权；不根据多个能力推断上一房间或存档前最后打出的场地。

## 当前效果的退场约定

- 真结局、好结局：外圈及外围粒子在 0.28 秒内淡出，后续能力短反馈继续显示。新建或恢复失败的场景从零亮度开始。
- 全屏裂纹：立即停止显示和绘制，保留原 2 秒伤害信号与 4 秒准备信号，准备完成后释放。延迟到来的保留请求不能重新唤醒它。
- 「结局」玻璃爆裂：属于短暂演出，不占场地槽。原裂纹已被替换时，仍可创建独立爆裂演出，不顶掉当前新场地。
