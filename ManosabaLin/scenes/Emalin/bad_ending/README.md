# 「好结局」审判庭特效

卡牌 `MANOSABA_LIN_CARD_EMA_BAD_ENDING`。由 `BadEndingVfx` 管理房间内的演出、伤害等待与能力外圈，`BadEndingPreloader` 在加载阶段提交真实绘制路径。

## 演出时序

| 时间 | 内容 |
| --- | --- |
| 0–1.42 秒 | 左侧大彩窗、右外大彩窗、右内小彩窗及各自的雕饰审判台，错开由下向上显现。没有共享圆盘底座，中央以柔边 `#CCCCCC` 下照光连接空间。 |
| 0.94–2.10 秒 | 粉白与暗红光丝汇聚为艾玛与希罗；第一帧在 1.35 秒完整显现，清楚停留约 0.75 秒。 |
| 1.15–2.45 秒 | 暗红流线汇向手部，2.10 秒切换凝剑姿态。不用程序扭曲手臂、衣发或身体。 |
| 2.45 秒 | 切到第三帧，剑击短光与声音，审判台上的窗光短暂亮起。 |
| 3.05 秒 | 切到第四帧骨刺姿态，同步冲击与 `impact_ready`；不额外手绘骨枝覆盖。原卡的 10 点全体伤害只执行一次。 |
| 3.13–4.9 秒 | 五层光环与碎光向全屏扩散，同时从中心展开完整审判庭原图，三组彩窗与审判台逐渐退去。 |
| 4.18–6 秒 | 两人靠拢停留，人物与审判庭按不同速度淡去；常驻外圈由扩散过渡显现。 |

常驻外圈是超出屏幕的连续椭圆，屏幕裁切成四角的弧形与少量边缘连接；不是矩形框。暖玫红亮芯、`#CC6666` 光带与酒红细丝分层流动，与真结局的冷粉白、银蓝外圈区分。人物、剑和能力命中颜色保持各自原有配色。

人物使用六张独立的 1254×1254 透明 PNG 依次播放，不再从原始 3×2 图集采样，避免原图跨格的头发、裙摆残片带入。第三帧额外的持剑手已在素材中修正。保持 PNG 原始 alpha，不再把边光叠进覆盖率而暴露透明像素中的底色。以脸、衣领、肩部和膝部的固定锚点计算每帧的等比缩放与平移，避免按变化的头发、骨翼外框定位而跳动；原图自身的动作差异仍保留。不做姿态插值、变形或交叉淡化；人物框占屏幕高度 88%，中心 (50%, 51%)。开场光景占高度 99%，位于人物下面。

左侧彩窗与审判台朝右，右外侧大窗与审判台朝左，右内侧小窗与审判台正对；侧框厚度、刻花台面与错位尺寸表现空间深度。装饰集中在拱肩、审判台边角与浮雕边框，大块石面保持安静；中央 `#CCCCCC` 光照亮内侧窗框与台面，外侧和台沿下方压出阴影。少量柔光带只沿左右外轮廓分布，宽缓的亮部随时间上移，玻璃不再整片高频闪亮。中央光在建筑后方，不盖住人影。剑刃和骨翅的亮部使用同一个 1.55 倍局部增亮参数，脸、持剑手与衣服保留既有基准亮度。

## 机制反馈

- `kind 1`：敌人重演层数实际增加后出现骨枝、彩窗形光印。
- `kind 2`：玩家获得决定能力时出现双色光印。
- `kind 3`：战后成功附加的实际卡牌汇向玩家；只有缓存已有卡图时才绘制卡图，缺图仍保留光印与轨迹。
- `kind 4`：附加卡实际自动打出前触发短光印，不额外等待、改写用途次数或伤害。

能力光印半径为原来的 1.6 倍，透光晕、尖瓣亮芯与末端碎光分层显示；保持清晰约 1 秒，再渐隐至 2.1 秒。卡图反馈从 224 像素高的光影卡面缓缓汇向玩家，反馈保留 2.3 秒尾段，避免战后清理截断。

资源与数值随机数无关；光点由固定视觉种子计算。保留原有先施加敌方能力、再攻击、再施加玩家能力的结算顺序。

保留外圈接入公共 `CombatFieldVfxSlot`：新真结局、好结局或满足条件的保留裂纹会替换旧场地。被替换的光圈和外围粒子在 0.28 秒内退去，能力机制与短反馈保留；恢复失败和附加卡通知从零外圈亮度开始，避免旧场地闪回。新效果的接入规则见 `ManosabaLinCode/Characters/Common/Vfx/README.md`。

## 卡顿控制

- `EmaEnding` 尚未转变时就预加载两种结局的资源并在入场时建立待命节点，避免首次点击才实例化。
- 加载期以相同 MSAA/HDR/过滤设置在临时视口绘制九个采样点，覆盖六个姿态、冲击、扩散、常驻及四类辅助反馈。
- 资源由场景预加载常量持有；不逐帧读取图像、生成纹理、解析文件或创建声音播放器。
- 最多 16 个短反馈、4 个卡图反馈、3 个短音效声部；演出结束后关闭背景、人物和扩散绘制，只保留外圈与 38 个光点。
- 人物区域外跳过纹理采样；光环离开有效光晕范围后跳过指数计算。
- 六张独立姿态图均在加载期持有并预热；人物 shader 只采样当前姿态，不同时混合六张图。彩窗、审判台、中央光和完整背景共用一个 shader，局部增亮和外侧流光不额外采样或创建后处理层。八张运行时 PNG 共约 18 MiB，声音为预生成 PCM，不在播放时合成。
- 所有视觉等待在场景退出、超时或异常时释放；特效不可用时卡牌仍正常结算。

## 美术与声音

`textures/courtroom.png` 使用用户提供的审判庭图，仅在最后扩散阶段展开。`textures/court_stage.png` 是内置 imagegen 生成的独立透明三窗与审判台。`textures/figure_01.png` 至 `figure_06.png` 为按用户六格参考逐帧制作的独立透明光影；旧 `figures_atlas.png` 仅保留源素材记录，不再用于播放。提示词与来源见 `art-prompts.md`。

`audio/opening.wav` 为 6 秒原创合成演出声音，`support.wav` / `card.wav` 为能力与卡牌短声，生成源码在 `tools/vfx/synthesize_bad_ending_sounds.py`。没有提取参考视频音轨。

## 验证范围

本轮仅静态核对代码、资源路径和本地引擎 API。按用户要求，未启动 Godot、游戏、浏览器、编译或测试；不能据此宣称已测得帧率或完全消除卡顿。

`.local/bad_ending_preview/bad_ending_preview_standalone.html` 是离线查看用的浏览器模拟文件，内嵌实际四个 shader 与资产，光丝粒子为 Canvas2D 对应实现；不是游戏实录。打开后由用户点击播放，可拖动时间轴。
