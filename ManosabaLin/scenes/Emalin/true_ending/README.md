# 「真结局」演出

卡牌 `EmaTrueEnding` 应用能力后播放开场；`EmaTrueEndingPower` 存在且未被新场地替换时保留屏幕外围流光。入口为 `ManosabaLinCode/Characters/Ema/Vfx/TrueEndingVfx.cs`，不替换原卡面。

## 演出节奏

| 时间 | 画面 |
| --- | --- |
| 0–1.82 秒 | 粉白与深红双核从两侧沿弯曲轨迹靠近、交绕、融合；附着光丝和细小花瓣。 |
| 1.25–3.48 秒 | 光粒沿弧线汇成居中的艾玛／希罗相拥光影。轻微肩部收拢、发梢衣摆滞后、泪滴下落、袖口花光逐个亮起。 |
| 2.94–5.30 秒 | 卷曲花纹以不同延迟展开；近景花瓣翻转，远景碎光较细，四层柔光波扩散到屏幕外。人物逐渐溶解。 |
| 4.05 秒起 | 超出屏幕四边的大椭圆环接入，画框裁出四角弧段；内侧流丝局部回到边缘，带少量花瓣。开场等待在 5.0 秒释放，剩余过渡自然完成。 |
| 能力移除／战斗结束 | 0.6 秒淡出并释放节点、音频及开场等待。 |

花纹采用半透明的书写式卷曲、残缺花瓣和流动亮线，避免写实花束和均匀辐射排布。各粒子使用固定局部随机序列，不消耗战斗随机数。全屏 Shader 均为叠加发光，原战场不额外压暗。

常驻外圈和外围碎光采用冷粉白、银蓝和冰白亮芯，与好结局的酒红、`#CC6666`、暖玫红区分；保持原有环形位置、层宽和时间，不改相拥人物与能力短反馈的配色。

## 起手卡顿与亮度调整

- 删除播放时的 `Texture2D.get_image()`、解压和逐像素采样。180 个光粒汇聚点由 `tools/vfx/cache_true_ending_contours.py` 提前保存到 `reunion_contours.gd`；原 PNG 未改动。
- `ExtraRunAssetPaths` 将场景交给游戏的预加载缓存，四个 Shader、两张纹理和三段音效作为场景的静态依赖保留。`TrueEndingPreloader` 等待原版 `LoadRunAssets` 完成后，在加载过渡期间实例化真实场景，以 320×180 离屏视口依次预绘制光核、汇聚、泪滴、扩散、外围与三种记忆反馈，每阶段等待两次实际绘制；视口沿用主视口的 MSAA、HDR 和纹理采样设置。全部完成才返回加载流程，无声音、不触发卡牌或能力逻辑。
- 预热完成按缓存场景实例与渲染配置去重；战斗加载入口补充检查，通常直接复用。超时或失败不阻断开局。临时视口随后释放，资源由原版 RunSet 缓存继续持有。进入战斗时提前建立静音待用节点，打牌仅激活；移除原先只画四个 1×1 Shader、遗漏全部 flow 图形且没有等待完成的房间内预热。
- 花瓣／光丝的叠加材质改为静态依赖 `additive.tres`，预热与正式播放共用，避免临时节点释放后又创建材质。花瓣图集区域初始化一次；人物适配与全屏材质尺寸只在视口尺寸改变时更新。三层光丝共用一次切线、法线与宽度渐消计算，保持原有轮廓、层宽和透明度。
- 光核半径、光晕尺度及拖尾宽度放大三倍；尾迹着色器采样从 18 次降到 12 次。
- 相拥光影按完整贴图等比居中：最大屏宽 92%、最大屏高 94%，取较小缩放率，头发、双手、裙摆均留在屏内；汇聚粒子、泪滴和袖口光同步使用该坐标。人影亮度使用与「好结局」相同的原图发光映射：原图 RGB 乘 `0.45 + 0.24 × 亮度`、细光密度 `0.86–1.0`，仅叠加少量细丝；移除旧的统一色调覆盖、指数曝光与额外透明度提亮。人物尺寸、构图、外圈及其他特效不受此次亮度调整影响。
- 扩散波保留宽光带、主亮脊及细丝副线。常驻外围参照视频后段改为同一屏幕中心的大椭圆环：三个环带的基础半轴分别为屏宽／屏高的 55%、57.8%、60.6%，四边超出画面，靠自然裁切形成四角的大曲率弧段。内部流丝以较小半径局部回到边缘作弧形连接，不再使用四个独立小角弧。提高线芯和有宽度的光带亮度，光晕只附着于环；80 个碎光／花瓣沿完整环形运动，屏外部分跳过绘制。
- 标记与收集反馈延长到 2.15 秒，增加大花光、手写弧线与碎光；十三种记忆完成反馈 2.65 秒，放大汇聚花纹并留出中央停留时间。

## 资源

- `textures/reunion.png`：1057 × 1488，RGBA，相拥光影；单张连贯人物贴图做连续微变形，避免姿态交叉淡入造成多手。
- `textures/botanicals.png`：1774 × 887，RGBA，四种抽象卷曲花纹与四种花瓣光片；按 `true_ending_flow.gd` 中实测不等尺寸区域取样。
- 两张 PNG 均由内置 `image_gen` 生成并保留原生透明通道。最终提示词及角色参考记录在 `art-prompts.md`。
- `audio/opening.wav`：5.0 秒，双核／交融／扩散。
- `audio/memory.wav`：0.8 秒，卡牌标记与首次收集。
- `audio/complete.wav`：1.5 秒，十三种记忆完成。
- 三段音频由 `tools/vfx/synthesize_true_ending_sounds.py` 原创合成，44.1 kHz 双声道 PCM16；未截取参考视频声音。

`true_ending.gd` 管理四个 Shader、图案运动及有上限的音效池。`true_ending_flow.gd` 管理光粒汇聚、花纹、泪滴、翻转花瓣和后续记忆响应。

## 接入与生命周期

- 每个能力拥有者最多一个演出控制节点，挂在当前战斗房间。
- 保留外圈通过公共 `CombatFieldVfxSlot` 与好结局、保留全屏裂纹互斥；新场地出现时旧外圈与外围粒子在 0.28 秒内淡出，能力、卡牌等待和记忆短反馈继续。恢复被拒绝时从零亮度开始，后续通知不会让旧场地重新抢占。新效果接入规则见 `ManosabaLinCode/Characters/Common/Vfx/README.md`。
- 开场信号、退场、房间销毁、异常与 6.5 秒看门狗均会释放卡牌等待。
- 能力实际不存在／被阻止应用时不创建演出；队友卡不触发本玩家的视觉响应。
- 成功附加标记：卡牌位置小花光；首次收集不同记忆：花瓣沿弧线汇入边缘；实际授予十三种记忆奖励：十三束花纹短暂汇聚后回落。
- 视觉事件上限 18 个，短音效池 3 路。持续外围无循环音效，跟随游戏音效响度与后台静音设置。
- `setup(player_uv, replay_opening, collected)` 可恢复外围或重播；`finish_effect()` 淡出；`seek_preview(seconds)` 静音定格。
