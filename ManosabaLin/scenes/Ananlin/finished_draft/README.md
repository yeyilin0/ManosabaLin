# 完稿：剧场演出特效

本轮重做范围：幕布动态与光感、蝴蝶翼拍与队形、牵线攻击、书写笔迹、资源预载。
截至 2026-10-18 只做了源代码和资源引用检查；没有运行构建、测试、Godot、游戏或浏览器，也没有测量实际帧率。旧版的验证记录不代表这一版已经通过运行验证。

## 演出

- 0–2.35 秒：旧紫色幕布从下缘向右拉开，上方稍后跟随。保留原绘制的织纹和花纹，增加折面明暗、边缘微光及渐弱的回弹。
- 24 只蝴蝶分四组、沿不同弧线飞入；前 10 只围绕玩家，其余分布在不同深度。全部使用原有十种魔法配色，轮廓和外光同色，不再混入统一蓝色或白色。大小、透明度与倾斜随飞行变化。
- 翼拍围绕身体独立折叠左右翅膀，身体与触角不再一起压扁。独立 SVG 保留原有 10 种翼形、真实魔法配色，增加很淡的翼膜；翼内没有点、花和星星。
- 每次攻击：牵线逐渐绷紧，光沿真实弯曲的线移向蝴蝶。蝴蝶在 0.78 秒到达目标，发出 impact 信号后继续沿另一条弧线回飞。每只蝴蝶保留自己的飞行时钟，下一击不会把上一只突然拽回。
- 笔迹约 570 设计像素宽，有四种倾斜/曲率、笔压粗细、细亮芯、收笔光点和飘散墨光。最多保留五道，2.15 秒内退去。
- 最后一击后 1.65 秒内放松牵线、散去蝴蝶、收起光照与幕布。

## 层级与亮度

原战场背景保留；幕布挂在角色的 GetBackVfxContainer，与艾玛翅膀一致。
幕布材质独立实例化，避免离屏预热或另一场演出共享动画参数。
幕布自身亮度系数从 2.15 提至 3.10，并提亮暗部，保留原有褶皱明暗与拉幕动作。
前景的蝴蝶、丝线与笔迹置于单独 CanvasLayer，并高于角色幕布所在层。
保留既定的 70% 场景降亮；#6666cc 聚光有柔软边缘、少量空气层次和椭圆落地光池。预备实例在正式开始时同步实际敌人锚点。

## 性能与生命周期

- 场景、幕布、着色器、10 张 SVG、光点纹理和声音均通过资源依赖提前加载。
- FinishedDraft 与 UnfinishedDraft 声明预载路径；入场和生成卡牌时准备休眠实例，正式播放激活该实例。
- 加载阶段在不可见的离屏 viewport 提交真实绘制，覆盖幕布、蝴蝶、牵线、笔迹与粒子；不会播放声音、扣血或占用场地槽。
- 彩色光点用固定 360 槽数组循环复用，每个光点绘制一张缓存的柔光纹理。停止发射后按寿命消失，不再逐帧移除 Dictionary。
- 牵线采样数组与飞行尾迹数组按蝴蝶缓存；笔迹几何在命中时生成，最多五道。
- 原来的单个多段 AttackCommand、伤害次数、Vigor、消耗和信号等待时机保留。
- 退出房间、脚本退出与 watchdog 都会释放等待并清理幕布。

音效沿用 curtain_pull.wav、theater_butterflies.wav、written_impact.wav，遵循游戏 SFX 音量与后台静音设置。
