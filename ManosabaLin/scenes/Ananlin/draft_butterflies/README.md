# UnfinishedDraft butterfly animation

Recorded magic bits are read from the card's existing `DraftMagic` enumeration and
`GetRecordedMagics()`; each selected magic produces exactly one butterfly with a stable
distinct form. Shapes are original line-art SVGs generated by
`tools/vfx/build_draft_butterflies.py`. They reveal from body to outer wings and flutter.
Positions are scattered with randomized separation across the upper/middle viewport using a
separate visual RNG, leaving card-generation RNG and saved progress untouched.

Color is read at runtime from the associated power's localized description, supporting
explicit `[color=#...]` and named tags using the game's `StsColors`. Noah's power contains
no color; its localized AnanlinNym card description marks the magic name with `[blue]`.

Ordinary playback lasts 2.5s and fades without a card. Completion playback lasts 4.25s:
after line drawing, butterflies follow curved paths into screen center and fade into an
actual `NCard` preview of the newly generated FinishedDraft, including its inherited
upgrade value. The same card is then added to hand; no duplicate card is generated for
visuals. A permanent upgrade that records the tenth magic during this play also completes
the animation using the updated recorded mask.

Damage, recorded magic application, permanent upgrade progress, completion condition and
inherited upgrade calculation are retained. Visual-only simulation skips the animation;
room removal releases waits, and a watchdog prevents a presentation fault blocking play.
C# build and static asset/color checks passed; runtime
rendering remains unverified under the current restrictions.

Completion explicitly exhausts the played draft, including when the tenth magic is
recorded during this play: the engine captures the ordinary destination before OnPlay.
The pooled NCard preview is refreshed after joining the scene tree so its title and
other labels match FinishedDraft. Butterflies use larger calligraphic silhouettes,
scalloped wings, sparse flower/star accents and a brighter tinted neon halo.

Outer orbital flourishes have been removed. On completion, ten broad marker strokes
draw from distinct sectors outside the viewport toward center, each matching its
butterfly's magic color. Wavy trajectories and irregular width curves mimic nib pressure.
Original synthesized stereo wing flutter starts with butterflies; dry felt-marker
paper friction starts at convergence (1.9s). Both follow the game's SFX volume setting
and are owned by the effect node. Sources: tools/vfx/synthesize_draft_sounds.py.
